--- the same afternoon, diagnosed: the sandbox's web proxy answers
curl at once, but Ruby's own HTTPS open to rubygems.org times out in
this environment. The workaround is to fetch the .gem file with
curl and install it locally. The file's SHA-256 is checked against
the checksum the rubygems.org API publishes for colorize 1.1.0
(30b5237f0603f666...), so the local file is provably the real gem.

$ curl -s -o /dev/null -w "%{http_code}\n" https://rubygems.org/
200
$ curl -sL -o colorize-1.1.0.gem https://rubygems.org/gems/colorize-1.1.0.gem
$ sha256sum colorize-1.1.0.gem
30b5237f0603f6662ab8d1fc2bd4a96142b806c6415d79e45ef5fdc6a0cfc837  colorize-1.1.0.gem
$ gem install --local colorize-1.1.0.gem
